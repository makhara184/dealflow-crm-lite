# DealFlow CRM — Lightweight Sales Pipeline

A fast, zero-backend Kanban CRM built for small businesses, operations teams, and solo sales reps who want clean pipeline visibility without bloated subscriptions.

## Features
- **4-Stage Kanban Pipeline**: New Lead, Follow-Up, Negotiation, and Closed Won.
- **Live Sales KPIs**: Automatically calculates active deal count, total pipeline value, closed-won revenue, and win rate.
- **Instant Search & Filtering**: Filter deals by title or contact name in real time.
- **One-Click CSV Export**: Export your entire sales pipeline to Excel or Google Sheets.

## Quick Start
Open `index.html` in any browser. Data is automatically persisted in browser `localStorage`.
